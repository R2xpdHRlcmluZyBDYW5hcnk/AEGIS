# 特征目录与页面查询

## 操作日志

独立特征管理器将任务的完整标准输出和错误输出写入私有状态目录的 `operation-logs`，日志文件权限为 0600，目录为 0700；不写入源码目录或静态资源。原子索引保留最近 20 次操作，并保留最近手动操作和最近定时操作的引用。手动更新、应用更改和手动特征应用均归入手动操作，定时任务不会覆盖其显示。进程重启后恢复记录；执行中断的任务标记为已中断，不自动重放。

状态快照只携带摘要与日志标识，完整正文通过需要登录的 `/api/actions/log` 按字节偏移分段读取，每次最多 64 KiB。服务端验证任务标识和偏移，不接受文件路径；UTF-8 字符跨分段时延后读取剩余字节。页面完整累积正文，保留日志区域滚动条，刷新后可重新读取完整内容；不再将状态接口的末尾摘要当作日志正文。旧版本没有保存完整文件的历史记录只能显示其已保留输出。

日志正文直接写入文件，内存中的状态预览保持有界。已有特征命令的运行时长及输出资源限制继续保留；触发限制时停止命令、执行既有回滚流程，并保留停止前捕获的全部输出。

## 目录查询与特征应用

特征页面通过 `/api/rules/page` 一次读取当前标签的数据、待应用状态和引擎状态。特征目录、特征分组和特征来源不额外生成治理列表；治理标签只读取一次治理数据。定时更新状态随特征来源页面返回。运行特征任务时暂停特征页的周期性整页刷新，任务状态继续独立轮询，完成后再刷新目录。

特征原文解析由 `backend/internal/console/rules.go` 管理，活动文件、上游目录及待应用视图共享只读目录快照。来源目录优先复用内置 Go 更新器的派生候选和完整分组映射，核对来源、解析器版本、归档收据和候选 SHA-256，包含当前未启用的特征。派生文件的变更也会使目录快照失效。普通特征文件限制为 128 MiB，压缩归档和派生候选限制为 256 MiB；超限返回明确错误，不静默隐藏来源。

派生缓存不可用时，目录读取器复用更新器的安全归档解析与兼容版本选择，排除 includes、删除目录和未导入模块。LightSPD 基础特征与版本增量的同一 GID:SID 可保留多个来源组。禁用、动作及告警抑制列表通过该目录解析特征名称，已禁用特征仍显示描述；目录中不存在的特征保留 SID 标识。

目录成员、编译动作、来源开关和内置特征状态独立派生。有有效派生缓存时，修改禁用策略无需重新解压上游归档。同一次只读请求固定目录快照，辅助函数复用已检查的目录；下一次请求重新检查文件元数据，发现新增文件或来源变化。来源加组名的选择器不变。

特征浏览顺序在目录变化时计算，普通翻页复用该顺序。来源可见性集合也在目录重建时计算。空的策略排除集合直接通过，不对每条特征反复规范化相同选择器。

未带搜索条件或策略排除的特征翻页直接复用目录对应的可见顺序，不在每次请求中遍历完整特征集合。目录文件、来源或策略变化时，该顺序与索引一起失效。分组详情先过滤成员、截取页码，再生成响应对象；同名来源的组通配选择先去重。特征解析先定位选项名称，正则仍校验完整边界；消息按连续未转义文本解析，保留转义字符。归档按顺序读取，成员流使用后立即关闭。

特征页切换标签、替换查询或关闭时取消旧 HTTP 请求。页面只保留当前页及跨页选中的特征信息，已浏览但未选中的原文及时释放。面板、日志及系统页共用的实时查询也会取消旧请求，并限制同一订阅的 REST 回退请求至一个；收到 SSE 帧后取消冗余回退，避免旧响应覆盖新数据。


Community 官方归档只提供 `snort3-community-rules/snort3-community.rules`，因此保留 `snort3-community` 单一分组。来源停用时，特征分组和检测特征页隐藏只属于该来源的特征；独立手动特征以及仍被其他启用来源提供的特征保留。

“应用更改”始终离线执行来源启停、禁用、动作和告警抑制策略，不下载特征。内置 Go 更新器生成的基础候选和分组映射保存在缓存的 `derived` 子目录；归档 SHA-256、候选 SHA-256、上游策略、快照及解析器版本匹配时直接处理本地策略。旧缓存首次使用时离线重新解析；没有归档时提示先更新，不退回在线模式。

“更新特征集”每次都重新下载官方归档和校验文件，或重新请求自定义源；没有 TTL、条件请求或内容未变时跳过网络的路径。手动更新在事务备份后应用整份待应用草稿，包括特征来源及 IPS 策略、禁用、动作、告警抑制、手动特征和封禁配置，下载后完成 Snort 配置校验与热重载，成功后清除待应用状态。下载、生成或校验失败时恢复原文件，不触发引擎重载；热重载失败时恢复原文件并重新加载原配置。失败保留草稿供修改或重试，恢复未完成时保留回滚材料并暂停后续特征写入。定时更新始终使用生效配置，保留未提交草稿。

特征任务先建立可读的空日志，再发布任务状态；准备草稿期间尚无输出属于正常等待。状态响应附带当前手动任务和最近定时任务各自的日志字节数，前端仅读取新增分段，空日志和已读完的日志不会触发失败提示。日志初始化失败时拒绝启动任务，实际读取错误仍按现有流程显示并重试。




阻断动作批量切换和特征来源启停在成功后移除已处理的选择；部分失败只保留失败条目。选择器弹窗向父列表报告实际完成的选择器，全部失败时保留原选择，便于重试。


验证时将所需特征文件及归档复制到开发电脑临时目录，在本地比较冷加载、缓存加载及策略文件变化后的查询，不在检测设备上压测。回归覆盖缓存容量与失效、策略编辑后的新状态、请求内快照、新文件发现、来源隔离和 Community 单组结构；浏览器回归检查加载、切换标签、保存及刷新只发出一份页面查询。
